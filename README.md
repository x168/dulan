# 台灣公共資金流向戰情室

Taiwan Public Funds Intelligence

整合台灣政府採購決標與中央、地方機關對民間組織的補助資訊，讓企業、記者與讀者查清楚「哪個機關、哪項計畫、公告多少金額、給哪個組織」。每筆分析都能回到原始來源。

本專案定位為服務政府市場的 **B2B 商業情報平台**。熱門公共議題提供免登入的完整可公開分析；一般企業的深度歷史研究採訂閱制，整理好的明細匯出採單次付費。決標與補助核定金額各自呈現，不直接當成實際撥款。

首版採非個人化設計：所有人使用相同搜尋、熱門專題及產業篩選；不做收藏、監控名單、個人推薦或 LINE／Email 通知。付費僅區分購買權限。

本次交付是專案方向與商業計畫修訂。儲存庫尚未提供可執行網站、已驗證的全台資料、付款服務或正式部署；定價、十年歷史覆蓋與商業成效仍須驗證。
